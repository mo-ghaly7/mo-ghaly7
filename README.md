I'm a Computer Science graduate pursuing a career in Security Operations and Cybersecurity. I have hands-on experience with SIEM tools, security alert monitoring, incident triage, log analysis, phishing investigations, and network traffic analysis.

I'm continuously developing my blue-team skills through cybersecurity labs, practical investigations, and hands-on learning platforms. My goal is to contribute to a SOC team by identifying suspicious activity, analyzing security events, and supporting incident response.

## Security Operations Workflow

How I approach an alert, from detection to documentation:

<div align="center">

| 01 | 02 | 03 | 04 | 05 | 06 | 07 |
|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| **Alert Detection** | **Initial Triage** | **Log Analysis** | **Investigation** | **Threat Validation** | **Escalation / IR** | **Documentation** |
| SIEM alert fires | Severity and scope | Correlate events | Build the timeline | True or false positive | Hand off to Tier 2 / IR | Record findings |

</div>

```text
[Detect] --> [Triage] --> [Analyze Logs] --> [Investigate] --> [Validate] --> [Escalate / Respond] --> [Document]
```
